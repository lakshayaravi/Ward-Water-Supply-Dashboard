# Ward Water Supply Measurement Dashboard

## Problem Statement

This project measures ward-wise water flow and displays readings using a React dashboard.

It helps identify unequal water distribution and faulty sensor readings.

---

## Technology Used

Frontend
- React JS

Backend
- Python Flask

Database
- SQLite

Simulator
- Python

---

## Steps to Run

Backend

cd backend

python database.py

python sample_data.py

python app.py

Frontend

cd ..

npm start

---

OPEN/CLOSED

recorded_at

Date and Time

device_id

Sensor ID

status

Normal
Missing
Out of Range
